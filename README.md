# Programming for Mechanical Engineers

This repository contains Python programming exercises for mechanical engineering students(programming 1).

The exercises are designed to connect programming concepts with engineering calculations, algorithm development, and physical reasoning.

## How to use the exercises

1. Open the lecture notebook on GitHub.
2. Read the problem description, equations, and guidance.
3. Write your solution in **Spyder** in a separate `.py` file.
4. Run your program.
5. Check the units and whether the result is physically reasonable.

The notebooks are used to present the exercises and engineering background.  
The final Python solutions should be written and tested in **Spyder**.

## Learning approach

The exercises follow the general workflow:

**Engineering problem → Algorithm → Python implementation → Physical check**

The goal is not only to obtain a numerical answer, but also to understand whether the program performs the intended engineering calculation.

The exercises are intended to be used together with the course lectures and *Think Python*.
